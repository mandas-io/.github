# mandas-io/.github

This repository contains organisation-wide GitHub configuration for 
[mandas-io](https://github.com/mandas-io).

---

## What's in here

| Path | Purpose |
|---|---|
| `profile/README.md` | Org homepage — shown on github.com/mandas-io |
| `ISSUE_TEMPLATE/bug_report.md` | Bug report template — applies to all repos |
| `ISSUE_TEMPLATE/feature_request.md` | Feature request template — applies to all repos |
| `pull_request_template.md` | PR template — applies to all repos |

---

## Making changes

All changes go through a pull request — direct commits to `main` are not permitted.

**Org profile (`profile/README.md`):** Update when new repos are added, 
the product description changes, or links become outdated.

**Issue and PR templates:** Update when the team identifies missing fields 
or recurring gaps in bug reports and feature requests.

---

## Repo and org standards

All mandas-io public repositories follow these conventions:

- Licence: Apache 2.0
- Default branch: `main`
- Branch protection: Rulesets enforced on `main`
- Required files: `README.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, 
  `CHANGELOG.md`, `LICENSE`
- CI: GitHub Actions lint and test pipeline on every PR

For questions, open an issue in this repository or start a 
[discussion](https://github.com/orgs/mandas-io/discussions).
